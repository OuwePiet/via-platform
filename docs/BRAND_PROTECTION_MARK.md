# VIA Brand & NFT Protection Mark — Approved Decision

Status: **APPROVED**
Decision date: 2026-09-08

## Brand roles

VIA deliberately uses two related visual marks with different jobs.

### Main VIA brand logo
Keep the previously approved elegant VIA identity with the mint-green leaf and `viadeso.online` for the main platform brand.

Primary uses include:
- site header and navigation;
- login/onboarding;
- general VIA communication;
- platform-level branding.

Do not silently replace the main VIA logo with the NFT protection mark.

### VIA Protection Mark
The newly approved detailed silver metallic leaf carrying the VIA lettering is the dedicated **VIA Protection Mark** for displayed NFT media.

Primary use:
- small and unobtrusive in the lower-right corner of displayed NFT media;
- transparent background so the underlying NFT remains visible;
- presentation/copy-deterrence layer only;
- may later be reused consistently for appropriate collector, certificate or Museum/Archive protection contexts after review.

The protection mark must not alter or be baked into the creator's original NFT media file. It belongs to VIA's presentation layer.

## Approved source asset
The approved visual is the silver embossed VIA leaf generated/selected in the VIA design discussion on 2026-09-08. It must be used as the visual source for the NFT Protection Mark rather than substituting a generic CSS leaf.

Before production asset integration, use a transparent-background PNG/WebP or equivalent reviewed derivative of that approved source, optimized for small display sizes while retaining a clean high-resolution master.

## Protection behavior
The visual mark works together with VIA's presentation deterrence such as disabling ordinary image dragging/context-menu downloading where appropriate. These measures discourage casual copying but must never be described as making screenshots or copying technically impossible.

## Master Audit rule
This decision supersedes any implementation that uses a generic substitute leaf for NFT presentation. The currently merged generic CSS leaf is therefore a temporary implementation and must be replaced by the approved VIA Protection Mark asset on a normal branch/preview/PR workflow.
