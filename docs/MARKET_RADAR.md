# VIA Market Radar

Status: active project baseline.

## Purpose

VIA should not merely reproduce the current DeSo ecosystem or an old NFT marketplace. The project continuously looks for needs the market is not serving well and translates useful gaps into VIA while preserving the researched Lumen/Vero/Velcon/VIA history.

## Fixed working method

For every market signal:

1. identify the user problem or missing capability;
2. search the complete historical VIA project stock first;
3. compare it with the current viadeso.online implementation;
4. verify external facts that can have changed;
5. prefer the safest, clearest, lowest-cost and most useful solution;
6. build directly when the addition is safe, factual and compatible with the VIA baseline;
7. put unresolved, costly, regulated or security-sensitive ideas in Fase 3 with the reason;
8. never add a feature merely because another platform has it.

## Current market signals

### Social discovery is part of the marketplace

NFT ownership and settlement do not solve discovery. Current research continues to show that visibility, creator networks and community interaction strongly shape NFT participation. VIA therefore treats Feed, Discover, creator profiles, collections and Marketplace as one connected product rather than separate websites.

Priority: improve transparent creator/art/collection discovery without pretending VIA has a canonical DeSo ranking.

### Storage transparency

Modern NFT marketplaces increasingly expose where metadata/media is stored (for example on-chain, decentralized storage or centralized servers). VIA already has substantial historical design work for DeSo references plus third-party media/storage, including durable/public storage and a separate private creator Vault concept.

Priority: eventually show a factual storage status on NFT/media detail pages. Never label storage permanent unless the actual storage path justifies that claim.

### Creator identity and provenance

Creator identity, ownership history, editions, holders and social context are more valuable when visible together. VIA should make provenance understandable without forcing ordinary users to understand blockchain internals.

Priority: connect creator -> post -> collection -> NFT -> owner/edition/history -> related social activity.

### International usability

VIA is intended to work internationally. Translation is an application-layer usability feature: keep the original DeSo content as source of truth, offer translation on demand, preserve regional language choices, cache responsibly and keep provider cost bounded.

### Sustainable creator services

VIA should not first create structural owner costs and hope for revenue later. Features that cause material third-party storage, bandwidth, processing or provider cost should be designed to cover their own costs where practical, with transparent pricing and a reasonable VIA margin where appropriate.

### Calm participation instead of forced speculation

VIA can support ownership, collecting, creator income, NFTs, service fees and sponsorship without turning every interaction into speculation. No gambling. Social and discovery features must remain useful without forced payment.

## Research watchlist

Continuously compare relevant developments from:

- DeSo protocol and official tooling;
- Focus and newer Nader/DeSo products such as Mirror when publicly verifiable;
- DeSocialWorld and other active DeSo applications;
- NFT marketplaces and creator platforms outside DeSo;
- storage/media providers and decentralized storage networks;
- creator-economy, discovery, moderation and accessibility patterns in mainstream social products.

This watchlist is an input, not authority. VIA adopts ingredients only after comparison with its own researched history and current architecture.

## Innovation test

A proposed addition should answer at least one of these questions positively:

- Does it solve a real user problem that is still poorly solved elsewhere?
- Does it make DeSo/NFT functionality substantially easier to understand or use?
- Does it connect social, creator and NFT information in a way competitors do not?
- Does it improve trust, provenance, storage transparency or resilience?
- Does it improve international or mobile accessibility?
- Does it reduce cost or create a responsible self-financing service?

If none apply, the feature is probably noise rather than VIA innovation.
